Antigravity Racer — road artwork attribution and rights
=======================================================

Files in this directory
-----------------------
  road-straight.png   2048 x 512, PNG-24 (8-bit RGB)    straight-track diffuse
  road-curve.png      2048 x 512, PNG-32 (8-bit RGBA)   curved / hazard-track diffuse
  road-emissive.png   2048 x 512, PNG-24 (8-bit RGB)    emissive decal sheet
  boost-arrow.png      256 x 256,  PNG-32 (8-bit RGBA)  boost-lane chevron

Author
------
  Patrick Ryan — Babylon.js team.

Rights
------
  The author of this road artwork holds the rights to it and explicitly granted
  this repository permission to redistribute these four images as part of the
  Antigravity Racer demo. They are therefore committed to git (unlike the demo's
  CC BY 4.0 ship/rock models, which are fetched at build time — see the
  generated CREDITS.txt one directory up). The credit "Track textures by
  Patrick Ryan" is shown on the demo's main menu.

Provenance
----------
  Extracted losslessly (byte-for-byte, no re-encode) from the four embedded
  base64 data-URI textures of the Babylon.js Node Material snippet 01HFES#76:

    https://snippet.babylonjs.com/01HFES/76

  which is the node material used by Cédric Guillemet's original antigravity
  racing playground (snippet WVPVWL). Their names here describe the role each
  one plays in that graph; the pixels are unmodified.

Sampler state carried over from the node material
-------------------------------------------------
  road-straight / road-curve : wrap U = clamp-to-edge, wrap V = repeat
  road-emissive / boost-arrow: wrap U = repeat,        wrap V = repeat
  all four                   : trilinear (linear min/mag + mipmaps),
                               invertY = false, sampled raw (no sRGB decode)
